Biometric Age Prediction — Frontend Architecture

Project: CogniAge AI • Hackathon: Cognizant Hackathon (Use Case #5) • Domain: Computer Vision & XAI

1. Executive Summary

The frontend for Problem Statement #5 (Age Prediction from Biometric Data) is engineered as a high-performance, real-time Computer Vision interface. It operates directly in the browser with 60 FPS hardware acceleration to detect facial boundaries, map a 31-node geometric landmark triangulation pattern strictly inside the face, and display biological age estimation and Explainable AI (XAI) feature breakdowns.

3. Side-by-Side Alternatives & Why We Selected Our Stack

Category Chosen Stack Alternative Why Chosen vs Why Alternative Rejected
Framework Vanilla JS (ES6+) React.js / Next.js / Angular / Vue Why Chosen: Zero build step, runs instantly on any machine by double-clicking index.html, no Node.js/npm dependencies.
Why Rejected: React/Next.js introduces heavy virtual DOM overhead, node module bloat, and build pipeline complexity.
Styling Vanilla CSS3 Tokens Tailwind CSS / Bootstrap Why Chosen: Direct control over exact HSL Royal Blue tokens, fluid responsiveness, and instant Light/Dark mode switching.
Why Rejected: Tailwind requires build tools (PostCSS/Node); Bootstrap is rigid and lacks biometric HUD styling.
Computer Vision MediaPipe + Canvas 2D OpenCV.js / WebGL / Three.js Why Chosen: 60 FPS performance, lightweight landmark tracking, easy mathematical 2D line and polygon triangulation.
Why Rejected: Three.js is heavyweight 3D overhead; OpenCV.js has huge WebAssembly download sizes (>10MB).
Application Delivery Web Browser Single Page Python Tkinter / PyQt5 / Streamlit Why Chosen: Cross-platform on any desktop/laptop/tablet without installing Python desktop GUI packages.
Why Rejected: Tkinter looks outdated; Streamlit re-executes whole scripts on every interaction and cannot do custom real-time canvas overlays.

4. Key Architectural Features

A. Real Face Landmark Tracking & Geometric Mesh

  • Tracks 31 key anatomical nodes (forehead hexagon, eye contours, nose bridge, cheeks, mouth, and chin tip) matching the project specification.
  • Constrained strictly INSIDE the detected face boundaries; no pattern leaks into the background.

B. Floating Age HUD Tag Below Face

  • Dynamically floats 12px strictly below the detected face bounding box, moving synchronously as the user tilts or moves their head.
  • Formats numerical age, margin of error (±2.1 yrs), and confidence score.

C. Explainable AI (XAI) Architecture

Explainability in Biometric Age Estimation:

Prevents algorithmic bias and black-box compliance risks by quantifying four biological aging zones: (1) Periocular/Canthal lines, (2) Nasolabial sulcus prominence, (3) Forehead skin texture smoothness, and (4) Mandibular jawline contour elasticity.

D. Decoupled Backend REST Connector

The frontend is completely decoupled from the machine learning model. Teammates can expose a standard REST endpoint: POST /api/predict-age returning { "age": 24.5, "confidence": 0.96 } for seamless plug-and-play integration.
